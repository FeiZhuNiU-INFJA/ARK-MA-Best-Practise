# 妙搭发布成本评估

## 本 Skill 的成本边界

本 Skill 默认发布的是用户已经拥有的 HTML，不调用妙搭 AI 生成页面。因此，“发布已有 HTML”与“让妙搭 AI 生成网页”是两条不同链路，不能把 AI 生成点数直接算到本 Skill 的每次发布上。

当前 `lark-cli apps` 发布、分析和观测命令不返回以下信息：

- 单次 AI 生成消耗的点数或 token。
- 账户套餐余量与账单。
- 某次 release 的人民币成本。
- 托管流量、存储或日志的最终计费明细。

因此，Skill 不能声称查到了“本次实际花费”。也不能根据文件大小、请求数或发布次数擅自换算金额。

## 可以输出的成本评估

如果用户提供当前有效的妙搭价格表、套餐规则或单位价格，可以按以下方式估算，并明确标记为“估算”：

```text
估算成本 = AI 生成次数 × 单次生成单价
         + 发布/构建次数 × 单次发布单价（若套餐明确收费）
         + 存储用量 × 存储单价
         + 在线流量/请求量 × 对应单价
         + 日志或其他增值用量 × 对应单价
```

本 Skill 可以提供的可审计输入只有：应用创建次数、release 次数、发布包文件数与字节数，以及 API 实际返回的请求/访问/存储指标。任何单位价格都必须来自用户给出的有效合同/价格表或另行授权的官方来源，并注明版本和日期。

## 标准结论

没有价格表时，返回：

> 这是现有 HTML 的妙搭托管发布，没有调用妙搭 AI 生成。当前 CLI/API 不提供单次发布的账单或 AI 点数，因而只能确认操作次数与用量指标，不能给出实际人民币成本。
