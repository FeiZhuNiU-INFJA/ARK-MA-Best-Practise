# 鉴权、安全与能力边界

## 基础依赖

- 飞书妙搭（Miaoda/Spark）应用能力。
- `lark-cli >= 1.0.95`。
- `apps` 用户授权域。
- Git，仅用于新式妙搭 HTML 应用的代码发布。

所有业务命令使用 `--as user --format json`。Skill 不使用应用机器人身份替代当前用户，也不把凭证写入交付目录、日志或发布记录。

## 鉴权流程

1. 运行 `scripts/resolve_lark_cli.py`，保存返回的绝对路径为本任务唯一 CLI；不得继续使用 PATH 中的裸 `lark-cli`。
2. 用该绝对路径读取版本并运行 `auth status --verify --json`，或先尝试一个只读 `apps` 命令。
3. 已登录且权限满足：复用现有身份，不重新授权。
4. 明确返回未登录或 scope 不足：发布只需 `apps` 域；启用进度播报时按缺失权限补充 `im` 域。不要无条件扩大 scope。
5. 需要人工设备授权时，把 CLI 返回的验证地址交给用户并暂停；不要宣称已登录。
6. 用户完成后验证身份，再恢复原步骤。不要因授权过期而新建重复应用。

## 允许的写操作

当用户明确要求发布已有 HTML 时，允许在该目标范围内：创建一个妙搭 HTML 应用、初始化仓库、导入已验证的交付物、提交和推送、创建发布。若用户指定现有 `app_id`，只有在身份与目标已核对后才更新。

访问范围变更不是发布的隐含组成部分，必须单独明确。高风险或不可逆的数据库、密钥、成员、角色、文件删除等操作不属于本 Skill。

## 发布与“复刻”的准确含义

“复刻”在本 Skill 中表示：以本地 HTML 交付物为发布源，尽量保持其文件内容和资源结构，然后通过妙搭托管。它不是把 HTML 截图给 AI 重画，也不是把需求重新交给模型生成。

SHA-256 能证明发布前本地源文件未被意外修改；妙搭 API 的 `finished` 能证明发布任务成功。两者都不能独立证明远端渲染与本地浏览器像素一致，也不能证明远端产物字节级等同于输入。

## 数据与隐私边界

- analytics 是聚合统计，不提供访客昵称、真实姓名或逐人历史。
- logs/traces 可能含 user ID 和业务字段，仅为运维诊断；不能自动做通讯录反查或用户画像。
- 发布 API 不返回妙搭 AI 生成成本、点数或人民币账单。
- API 不支持访问范围查询时，结论只能是“无法通过当前 API 确认”。
- 空数据、延迟数据和权限不足必须分别表述，不能统一说成 0。

## 明确禁止

- 用浏览器内置页面或管理后台 DOM 获取数据。
- 手工拼接发布 URL。
- 因 Git 鉴权失败降级到错误的遗留发布模式。
- 用 `--allow-sensitive` 无条件跳过敏感文件检查。
- 在未确认目标时覆盖同名应用。
- 将 token、device code、cookie、密钥或原始敏感日志写入 Skill、共享上下文或交付记录。
