## 目标

根据标题、描述，判断内容语义关联到营销节点日历中的哪些节点，并对每个关联节点逐层判断：是否构成节日营销相关内容、有没有具体品牌参与、这个品牌的动作是不是专门为该节点定制的。四层输出：节点识别、是否节日营销、涉及品牌、是否节点定制营销。

判断以标题为主语义单元，标题决定内容真正在讨论哪个节点；描述只用于消解标题歧义、补充细节，不是与标题平级的独立候选来源。

## 判断标准

### 第一层：节点识别

只负责召回，不判断这次提及是否与营销相关，只判断标题/描述是否语义上关联到某个节点。

1. 对照"营销节点参考表"核对，满足其一即识别为关联节点：
   - 标题/描述出现节点的标准名称或常见别名
   - 标题/描述描述了该节点公认的应景场景/习俗（例如"秋天第一杯"对应立秋）
2. 候选为二十四节气时，应景场景判定收紧：仅泛泛描述天气变化、换季感受、季节仪式感，不算应景场景，不识别为关联节点
3. 未出现节点名称/别名，也没有描述应景场景，只是泛泛的节日氛围表达，不识别为关联节点
4. 参考表中找不到对应节点、或标题中的词只是普通日期用语而非真正的营销节点专有名词，不识别为关联节点
5. 标题中出现参考表外的节点专有名词，若属于公众普遍认知的法定节假日/节气/知名电商大促/少数民族传统节日（如那达慕、苗年节、藏历新年等），同样识别为关联节点；若只是普通日期用语或生造词，不识别
6. 描述里并列提到多个同类节点、作泛化类比或情感模式描述（例如"每次到了清明中元都会想起…"），且内容并未分别就每个节点单独展开，只识别标题真正讨论的那个节点，不把并列类比的其他节点也单独输出
7. 同一条内容允许识别到多个关联节点，前提是内容确实分别围绕这些节点展开（如"中秋国庆拼假出游"同时讨论两个节点），不是规则6里的并列类比场景
8. "提取节点"填参考表标准名称，去掉品牌名/年份/"营销""活动""案例"等修饰词；标题中出现的别名先按参考表映射为标准名称再输出

### 第二层：是否节日营销

对第一层识别出的每一个关联节点单独判断，取值"是"或"否"。

判"是"：内容主题确实是该节点本身的消费/活动/习俗/文化氛围/商业现象展开，不要求存在商业营销主体或营销动作。形式不限：品牌活动、平台促销、公益活动（该节点的主题活动本身）、网民讨论/吐槽、事后复盘、节点习俗科普。

判"否"：内容主题是发生在该节点当天或附近、与节点本身场景/消费/情感无实质关联的另一件独立事件，节点名称只是时间戳，不代表内容围绕节点展开。常见形式：天气数据播报、自然灾害、事故通报、无关人物动态、与节点无关的社会新闻。

第二层判"否"的节点，第三层、第四层直接留空，不需要判断。

### 第三层：涉及品牌

仅对第二层判"是"的节点判断。

抽取内容中出现的具体品牌/商业主体名称，多个品牌用"、"分隔。以下情况留空：
- 内容是网民讨论/吐槽/习俗科普，没有任何商业主体参与
- 只有"各大商场""某平台"这类泛指，没有指名到具体品牌

### 第四层：是否节点定制营销

仅当"涉及品牌"非空时判断，取值"是"或"否"；"涉及品牌"为空时，本层直接留空。

判断这个品牌的这次动作，是不是专门为这个节点设计的，而不是恰好在节点附近发布、只是拿节点做了个时间包装。满足以下任一信号，判"是"：
- 文案/活动名称直接使用了该节点的专属概念（参考表"常见别名"列或应景场景，如"秋天第一杯""七夕限定"）
- 营销主张的核心诉求直接对应该节点公认的文化内涵（如七夕对应爱情/礼赠，立秋对应换季/尝鲜）

反证信号，判"否"：把内容里节点相关的词去掉，这个品牌活动的核心创意/卖点依然完整、不受影响（例如怀旧金曲改编、跟节点内涵无关的产品发布），说明节点只是发布时间的包装，不是这次营销的创意起点。

## 输出格式

仅输出单行 JSON，不加 markdown 代码块，不加解释文字。

schema：

```
{"关联节点":[{"提取节点":"","是否节日营销":"","涉及品牌":"","是否节点定制营销":"","相关依据":""}]}
```

- 第一层未识别到任何关联节点：`{"关联节点":[]}`
- "是否节日营销"：枚举值仅为"是"或"否"，必填，按第二层标准逐个节点判断
- "涉及品牌"：第二层判"否"时留空；判"是"时按第三层标准填品牌名或留空
- "是否节点定制营销"：枚举值"是"/"否"/留空（留空的条件见第三层、第四层规则）
- "相关依据"：一句话，15-40字，说清内容主题与该节点的具体关联点；若涉及品牌判断，同时点出判定"是否节点定制"的关键线索（用了什么应景概念，或说明创意跟节点无关）
- 含双引号/反斜杠/换行按 JSON 标准转义

## 禁止

- 不要跳过第一层直接判断"是否节日营销"，第二层只对第一层已识别出的节点逐个判断
- 不要在第一层用"主题是否营销相关"这个标准过滤，第一层只管有没有出现节点名称/别名/应景场景，过滤留给第二层
- 不要把"是否节日营销"字段留空或省略，每个识别到的节点都必须带这个字段
- 不要把描述里并列类比提及、内容并未单独展开讨论的同类节点也当独立候选输出，标题才是判断内容真正讨论哪个节点的主要依据
- 第二层判"否"时，不要继续判断"涉及品牌"和"是否节点定制营销"，直接留空
- 不要把"各大商场""某平台"这类泛指也填进"涉及品牌"，必须是指名到具体的品牌/商业主体
- 不要只因为内容里出现了品牌名就判"是否节点定制营销=是"，要看这个品牌的营销创意是不是真的跟节点内涵绑定，跟节点无关只是蹭时间戳的，判"否"
- 不要自行创造参考表之外且不属于公众常识节点的名称
- 不要在"相关依据"中使用"日期相近""时间接近"等与内容语义无关的措辞
