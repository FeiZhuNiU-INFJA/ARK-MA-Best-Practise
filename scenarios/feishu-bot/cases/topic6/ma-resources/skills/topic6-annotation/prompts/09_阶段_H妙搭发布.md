## 输入

| 参数 | 路径 / 来源 |
|---|---|
| 待发布 HTML | `status.g.output_dir` 下的 `index.html`（自包含，无外部资源依赖） |
| 应用名 | `热点报告_{period_label}`（`period_label` 取自 `run_config.yaml` 的 `period.period_label`） |
| 已有 app_id（若有） | `status.h.app_id`——**存在则走"更新已有应用"路径，不存在才走"新建应用"路径**（同一项目重跑/补发不应重复建新应用） |

## 执行步骤

1. **确认输入**：源路径 = 上表「待发布 HTML」；`status.h.app_id` 为空 → 新建，
   非空 → 更新已有 HTML 应用。
2. **尺寸预检**：单个 HTML ≤ 10MB、打包后 ≤ 20MB、未压缩总量 ≤ 200MB；任一超限立即停止。
3. **用户身份检查**：妙搭应用属于用户资产，全程显式使用 `--as user`。首次使用或缺少
   apps scope 时执行 `lark-cli auth login --domain apps --no-wait --json`，把授权 URL
   交给操作人完成 OAuth；授权完成前保持阻塞，不得降级为 bot 身份。
4. **创建应用**：`status.h.app_id` 为空时执行
   `lark-cli apps +create --name "热点报告_{period_label}" --app-type html --as user`，
   并保存响应中的真实 `app_id`；已有 `app_id` 时直接复用。
5. **发布**：先对同一输入执行 `apps +html-publish --dry-run`，通过后执行
   `lark-cli apps +html-publish --app-id <app_id> --path <index.html> --as user`。
6. **链接解析**：只读取成功响应中的 `data.url`，不得手工拼接，也不得使用开发态链接代替。
7. **结果交付**：把 `app_id` / `release_status=finished` / `online_url` / 源文件 SHA-256
   写回 `run_config.yaml`。

### 飞书通知

```bash
CHAT_ID=$(echo $CC_SESSION_KEY | cut -d: -f2)
lark-cli im +messages-send \
  --chat-id "$CHAT_ID" \
  --text "热点报告已发布至妙搭：{period_label}\n公网链接：{online_url}" \
  --as bot
```

非飞书会话环境下（没有 `CC_SESSION_KEY`）跳过通知，只完成 run_config 写回。

## 质量检查

- [ ] `apps +html-publish` 返回成功，且 `data.url` 非空
- [ ] `online_url` 非空且是妙搭域名下的可访问链接（不是本地路径、不是手工拼接的猜测值）

不通过：OAuth 未完成或发布失败 → 停止并返回可恢复步骤，等待授权或重试；
**不静默重试、不自动改用其他托管方式**。

用户 OAuth 未完成或 `lark-cli apps` 不可用同样属于阻塞：保持
`status.h.completed=false`，不得写 `current_phase=done`，不得声称“demo 已覆盖完整流水线”；
飞书文档 URL、本地 `index.html` 路径和 HTML snapshot URL 都不能替代妙搭 `online_url`。
