## 执行

```bash
python skill/fetch-normalize/sample_500.py \
    --project-dir "Projects/{PROJECT_DIR}"
```

`--project-dir` 模式会自动推断输入输出路径（`02_标准化/hot_topics_normalized.xlsx` →
`03_抽样/sample_500.xlsx`）。也可用 `--input` / `--output` 显式指定，二者互斥。

可选参数：`--size`（默认 500）、`--seed`（默认 42）。

---

## 抽样口径

| 项 | 规则 |
|---|---|
| 分层依据 | `platform` 列（微博/抖音/B站/知乎） |
| 配额分配 | 按各平台行数占比，**最大余数法**（Hamilton）确保总数恰好 = 500 |
| 平台行数不足配额时 | 取该平台全量，余量追加给行数最大的平台 |
| 随机种子 | 固定 `seed=42`，**结果可复现** |

**为什么要分层而不是简单随机**：四平台行数差异大（微博约占 54%），简单随机会让小平台在 500 条样本里只剩个位数，HC1 无法判断该平台的标注质量是否达标。

## 一个需要留意的提示

当数据总量 ≤ 抽样上限时，脚本会输出：

> 当前样本 = 全量（无抽样偏差）。

test 仍按 HC1→HC2 执行；demo 按定义只走 HC1，随后跳过全量与 HC2。
