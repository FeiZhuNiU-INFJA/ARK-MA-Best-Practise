| 项 | 缺失后果 | 严重度 |
|---|---|---|
| `DATAHUB_API_KEY_OFFICE` / `_HOME` / `DATAHUB_API_KEY` | Phase C 报错退出 | 阻塞 |
| `ANTHROPIC_API_KEY`（可配 `ANTHROPIC_BASE_URL`） | Phase E 报错退出 | 阻塞 |
| `BLUEAI_API_KEY`（或 `~/.claude.json` 里 crawler-hot-topics-server 的 Authorization） | Phase A 报错退出 | 阻塞 |
| `FEISHU_HOTREPORT_FOLDER_TOKEN` | Phase F 在导入步骤暂停等设置 | 阻塞 |
| **Python ≥ 3.10** | 脚本用了 `X \| None` 注解，3.9 在 import 阶段即 `TypeError` | 阻塞 |
| `blueai-canonical-event-registry` skill 已安装 | C2 跑不了，E1/E3/E4 失去聚合主键 | 阻塞 |
| `MARKETING_CALENDAR_PATH` | **E2「本周节点预告」静默跳过，不报错** | ⚠️ 静默降级 |
| `CC_SESSION_KEY` | 跳过飞书通知，不阻塞落盘 | 可接受 |
| `artifact-template-bluefocus-hotspot-web-report` skill 已安装 | Phase G 跑不了（F 已交付，可接受） | 低 |
| `authorized_users.json`（白名单） | 启动第一步读不到文件 | 阻塞 |

> ⚠️ `MARKETING_CALENDAR_PATH` 那一行是最危险的 —— 它是**唯一一个缺失后不报错的**，
> 报告会少一个小节而没有任何告警。部署时必须主动核对。

> ⚠️ 外部 skill 的探测路径在 macOS 上有盲区：`c2_run_all_platforms.py::_find_skill_scripts()`
> 第一候选用 Windows 的 `%APPDATA%`，mac 上该变量为空会退化成相对路径；它只会回落到
> `~/.agents/skills/` 和 `~/.claude/skills/`，**不会**探测 macOS 的
> `~/Library/Application Support/CherryStudio/Data/Skills/`。在 mac 部署时 skill 必须装到前两个位置之一。
