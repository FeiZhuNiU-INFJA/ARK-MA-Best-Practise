# V5｜C0 基础事实层（紧凑版）

## 任务

从单条社媒热点中抽取基础事实，并判断它是否能为营销、公关或内容运营提供具体参考。
只处理本层字段，不判断商业合作、风险预警等 R1~R5 标签。

输入以标题为主；平台只辅助识别内容形式；描述只用于消歧。商业实体和热点驱动词只能
取自标题。按下面 1~9 的顺序判断，最后只输出一行 JSON：

```json
{"商业实体":"","热点驱动词":"","行业归属":"","营销触发方式":"","营销维度":"","平台原生形式":"","不可用原因":"","是否营销可用":"","判断说明":""}
```

## 1. 商业实体

提取标题里可直接指认的具名主体，按出现顺序，最多 3 个，以 `|` 分隔：

- 品牌、产品、企业、平台、机构
- 明星、运动员、网红、达人
- IP、作品、游戏、动漫、角色
- 赛事、奖项及其他有商业授权价值的具名对象

不提取：纯品类、玩法形式、情绪修辞、网络梗、抽象概念、代词或泛指对象
（如“涉事银行”“某品牌”）。无则 `null`。

## 2. 热点驱动词

提取 1~3 个能解释“为什么上榜”的标题原词，按驱动力降序，以 `|` 分隔。可包含：

- 本身就是传播核心的明星、品牌、IP、赛事
- 梗、句式、冲突、情绪词、玩法名
- 无具体品牌时的品类词

不做语义改写，不抽纯背景。无则 `null`。

## 3. 行业归属

从以下白名单选最多 3 项，按相关度降序；只看核心主体、产品、服务、作品或赛事：

`美妆护肤、个人护理、家清家护、食品零食、饮料、酒类、母婴、宠物、服饰鞋包、
数码3C、家电、家居家具、汽车出行、餐饮连锁、文旅酒店、体育赛事、金融、教育、
医疗健康、游戏、影视综艺、IP/潮玩、科技/AI产业、能源化工、音乐、房地产`

规则：

- 具体品类优先：AI 手机→数码3C，新能源车→汽车出行。
- 联名、代言、赞助可同时命中品牌行业与赛事/节目行业。
- 人物职业不是行业；作品+人物按作品领域。
- 季播综艺→影视综艺；纯音乐、音乐节、音乐颁奖礼→音乐。
- 连锁现制门店→餐饮连锁；预包装饮品→饮料。
- 母婴、宠物优先于食品/护理；运动鞋服→服饰鞋包。
- `IP/潮玩` 仅用于潮玩、手办、盲盒、实体周边；裸作品名应按已知媒介归影视或游戏，
  无法判断才输出 `null`。

## 4. 营销触发方式

枚举仅限：`主动营销、被动卷入、无主体潜在机会、无`。

按顺序判断：

1. 主动营销：品牌、企业、平台、机构、明星等主动发起代言、官宣、发布、联名、活动、
   直播带货、赠送或官方回应。
2. 被动卷入：具体主体因网友曝光、媒体报道、意外走红、纠纷、销量变化、政策冲击、
   作品或人物讨论等被带入热点。
3. 无主体潜在机会：没有具体主体，但命中行业白名单，并呈现消费趋势、行业技术进展、
   行业风险或统计对比。宏观金融和政策资讯不走此项。
4. 无：以上均不满足。

只要商业实体非空，通常只能选主动营销或被动卷入。国家监管机构、政治人物及纯知识
题材中的历史人物不是商业主体例外；其内容可判“无”。

## 5. 营销维度

独立判断，最多 3 项，以 `|` 分隔：

- `品牌/产品相关`：具体品牌、产品、Campaign 或品牌官方动作。
- `品类/行业相关`：具体消费品类或行业趋势。
- `明星/IP相关`：明星、运动员、达人、作品、游戏、角色。
- `消费群体/情绪相关`：明确群体在消费领域的集体情绪、偏好、信任或争议。
- `营销垂类相关`：讨论营销、公关执行手法或效果；单纯联名、代言事实不算。

后两项不要求商业实体存在。无则 `null`。

## 6. 平台原生形式

输出字符串 `"是"` 或 `"否"`。

与原事件无关的品牌或账号，能否照着一个明确动作、BGM、挑战、拍摄/剪辑手法、
视觉风格、梗图/口播模板、互动机制或萌宠反差套路复刻？

- 能复刻具体形式→是。
- 只有话题、观点、新闻、人物状态或纯文字调侃，没有明确形式载体→否。

## 7. 不可用原因

先判断是否属于以下排除项。命中则输出对应值；不命中输出 `无`：

- `纯时政新闻`：外交、军事、政策、宏观经济、货币政策、国际金融等资讯。具体企业、
  品牌、产品动作不属于此项。
- `纯灾难信息`：灾难、事故、犯罪，没有品牌应对或安全业务延伸。
- `纯便民信息`：城市公告、天气与生活服务通知。
- `纯赛事数据`：日常胜负、积分，没有情绪、明星或赞助延伸。
- `纯个人纠纷/消费投诉`：一次性个人纠纷，无品牌公开应对或规模化舆情。
- `纯娱乐八卦`：明星、运动员、网红、虚拟角色的私生活、外貌、私人行程、粉丝向内容；
  有明确作品宣发、代言或可复刻玩法时不属于此项。
- `信息不足/泛UGC内容`：仅当商业实体和行业归属均为 `null`，且无具体形式、群体情绪
  或营销执行价值时使用。
- `其他：{10字内具体原因}`：确实无营销参考价值但不属于以上类别，例如
  `其他：纯历史知识讨论`。
- `无`：不存在排除原因。

一致性约束：

- `信息不足/泛UGC内容` 与非空商业实体、行业归属、`消费群体/情绪相关`、
  `营销垂类相关` 任一项冲突。
- 具体剧名、角色名或作品名出现时，不能仅因八卦式表达判纯娱乐八卦。
- 纯娱乐八卦、时政、知识讨论可以同时有标题实体和“被动卷入/无”，排除原因优先决定
  最终是否可用。

## 8. 是否营销可用

- 不可用原因不是 `无` → `"否"`。
- 不可用原因是 `无` → `"是"`。

输出“是”前必须能说出具体下一步：合作对象、可借的形式、品类洞察、风险监测或内容选题。
若只能写“值得关注”“可借势营销”之类空话，回到第 7 步选择准确排除原因。

## 9. 判断说明

始终输出一个不超过 40 字的单句：

- 可用：写清主体/品类 + 动作、形式或信号 + 可执行参考。
- 不可用：写清内容性质 + 无法用于营销的具体原因。

禁止模糊词、价值吹捧、趋势预言、分点或换行。第 6 步为“是”时必须写出具体形式。

## 输出硬约束

1. 只输出单行 JSON，不要 Markdown 或解释。
2. 字段名和顺序必须与模板完全一致。
3. 多值字段用 `|` 分隔，不加空格。
4. 空值统一使用 JSON `null`，不是字符串 `"null"`。
5. “是/否”字段必须是字符串。
6. 枚举字面不得改写。
