## 为什么这是全链路的总闸门

下游 **R1~R5 与四个报告版块的统计，全部先过滤「是否营销可用 = 是」**。这一个字段判错，会污染整份报告。

Prompt 原文：「下游 R1~R5 及所有报告版块的统计都先过滤'是否营销可用=是'这个条件，判断错误会污染全部下游」。

反过来，它也是成本闸门 —— 筛掉约 40% 的下游调用量。C0 完成后由纯脚本（零成本）切出可用子集，R1~R5 + C2 只吃这个子集。

历史参考值：「是否营销可用 = 是」的占比约 **55~58%**（v3 实测 53.91%）。显著偏离时应人工复核，而不是直接放行。

## 它抽取的 5 类事实

| 事实 | 业务定义 | 判定要点 |
|---|---|---|
| 商业实体 | 标题中的**具名**主体（品牌/IP/明星/机构/赛事等 6 类） | 泛指词不算 —— 「涉事银行」「某品牌」这类**没有给出具体名称、只是泛指某一类主体的，不算具名实体** |
| 热点驱动词 | 解释「为什么能上榜」 | 区别于商业实体的「谁在场」 |
| 行业归属 | 26 项白名单内取值 | 供后续步骤直接复用 |
| 营销触发方式 | 主动营销 / 被动卷入 / 无主体潜在机会 / 无 | 见下方自洽性约束 |
| 平台原生形式 | 是否具备可复刻的形式载体（挑战/BGM/拍摄手法/模板等） | — |

## 「营销可用」怎么判

**判定方式是反向排除**：列出不可用原因，**一条都不命中才算可用**。

| 不可用类型 | 边界说明 |
|---|---|
| 纯时政 | **含宏观财经、央行讲话** —— 即使命中金融行业白名单也判不可用 |
| 纯灾难 | — |
| 纯便民 | — |
| 纯赛事数据 | 单纯比分/战绩播报 |
| 纯个人纠纷 / 消费投诉 | 单一个案，无规模化 |
| 信息不足 / 泛 UGC | **须同时满足**「无实体锚点」+「行业归属为空」两个条件 |
| 纯娱乐八卦 | 无剧名/角色名锚点才算 |
| 其他：{原因} | 兜底，必须写明具体原因 |

### 可执行性复核（最重要的一条）

> 把判断说明读给一个真实的营销/公关从业者，他/她能不能说出下一步具体要做什么？

**答不出即回退判否。** 这条是在防「能编出一句借势话就算可用」的伪阳性 —— 例如「XX 品类可借势做内容营销」这种空话不构成可用理由。

## 已知易判错的边界（原文示例）

| 案例 | 正确判定 | 为什么容易错 |
|---|---|---|
| 「美联储主席就任后首次讲话」 | **不可用**（纯时政） | 命中金融行业白名单，看起来像可用 |
| 「栾念疯狂勾引尚之桃」 | **可用**（影视宣发） | 有具体角色名锚点，不归纯娱乐八卦 |
| 「多名农民称莫名成企业法人被贷款」 | 「涉事银行」**不算**具名实体 | 泛指主体易被误采为商业实体 |

## 自洽性硬约束

**商业实体非空时，禁止选「无主体潜在机会」或「无」。** 原文：即使该主体只是被提及、无明显主动动作，也应判「被动卷入」。

这是 v4 相对 v3 的核心修复项 —— v3 有 5.4% 的行违反此约束（500 条中 15/280）。
