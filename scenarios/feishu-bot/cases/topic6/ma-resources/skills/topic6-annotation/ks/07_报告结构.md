## 报告标题格式（pipeline_f.py 实际输出）

```
# 社媒热点周刊 · {period_label}

> 数据范围：微博、知乎、抖音、B站
> 数据周期：{period_label}（{date_start} ~ {date_end}）
```

四版块之间以 `---` 分隔。

---

## E1 · 行业及热门话题

**数据来源**：是否营销可用=是，按行业归属分组（explode多值字段）。

**表格**（5列）：行业 / 热点总计（条）/ 最高热度分 / 代表事件（TOP3）/ 主要驱动话题。取TOP10。

## E2 · 营销节点

**数据来源**：是否营销可用=是 且 提取节点非空，二次核对节点日历锚点日期。

分两个子部分：
- **上周节点回顾**：表格（6列）节点 / 热点总计 / 热度值 / 涉及品牌IP / 涉及品类 / 代表热搜
- **本周节点预告**：表格（4列）节点日期 / 节点名称 / 节点类型 / 品类机会（依赖 `MARKETING_CALENDAR_PATH`
  环境变量，见 `prompt/运行前置.md`，未设置则本子部分跳过）

## E3 · 平台新鲜事（微博/抖音/B站/知乎各自独立分析）

**数据来源**：是否营销可用=是 且 platform=对应平台。

- **热点事件TOP5**：表格（6列）排名 / 事件名称 / 热搜条数 / 代表热搜 / 最高热度分 / 行业
- **借势玩法TOP3**：表格（5列）玩法话题 / 热度分 / 所属事件 / 适配领域 / 借势方向（<2条时该平台跳过此子部分）

## E4 · 营销发现

**数据来源**：R2/R3/R4/R5 各自独立布尔字段（是否商业合作/是否风险预警/是否营销发现/是否消费者行为）。

四个子部分：
| 子部分 | 筛选字段 | 呈现形式 |
|---|---|---|
| 合作动态 | 是否商业合作=是 | 按变动类型分组表格（5列：事件/代表热搜/行业/热度分/备注） |
| 舆情风险 | 是否风险预警=是 | 按风险类型分组表格（3列：风险事件/具体热搜/风险影响） |
| 营销观察 | 是否营销发现=是 | 案例卡（每案例：原始热点/营销发现/链接/配图占位） |
| 消费洞察 | 是否消费者行为=是 | 洞察卡（每条：群体/触发事件/行为反应/营销发现） |

## 写作规范关键点

- 数字必须可在合并宽表（`05_合并/wide_table_full_r{N}.xlsx`）中追溯，不出现"约""估计""大概"
- 热度值**分版块两种格式**，不出现"X 万"原始值：
  - **E2 / E4 带「分」**（如 `80.7 分`）
  - **E1 / E3 裸数字**（如 `80.7`），不带「分」字 —— E1 见 `e1_industry.py`，E3 见 `fmt_score(v, suffix="")`
  - 原写「统一 X 分」是错的，2026-09-20 按代码校正；口径详见 `ks/05_四版块统计口径.md`
- 详细措辞禁止清单、各子部分字数上限、边界条件：见 `ks/06_表达规范.md` 和
  `ks/05_四版块统计口径.md`
