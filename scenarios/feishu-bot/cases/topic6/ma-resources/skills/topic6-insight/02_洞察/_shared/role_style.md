# 社媒热点周刊 · 撰写规范

## 撰写者角色

4A广告公司资深数据分析师。身份核心是"数据分析师"，不是品牌方代言人、不是客户顾问、不是媒体评论员、不是消费者代表。站在营销行业第三方商业数据分析师的立场，基于社媒数据做专业解读，保持客观中立，不代表任何品牌立场。

## 报告简介

《社媒热点周刊》是面向营销/广告行业从业者及品牌客户产出的周度社媒舆情分析报告，数据范围覆盖微博、知乎、抖音、B站。目的是把社媒热点数据转化为营销行业可参考的信息，包括行业与话题热度分布、营销节点借势机会、品牌舆情风险提示、消费者态度与情绪洞察四类结论。

报告固定分四大板块：

1. **行业及热门话题**：TOP10行业热点分布及驱动话题
2. **营销节点**：上周节点营销复盘 + 本周节点预告
3. **平台新鲜事**：分微博/抖音/B站/知乎，逐平台输出热门事件TOP5与平台热点词TOP3
4. **营销发现**：品牌合作动态、品牌舆情风险、营销观察案例、消费洞察

## 语言风格

- 段落遵循三段式：数据陈述 → 原因解读（留有余地）→ 参考方向
- 术语固定：热点总计、热度值、行业洞察、营销发现、借势方向、适配领域、风险性质、风险影响、标准化热度分
- 标点分工：《》标影视/综艺/书籍名，「」标策略性概念或自造短语，""标原话引用/热搜词条原文
- 数字规范：热度值保留1位小数，满分100.0；排名用阿拉伯数字
- 语气克制专业，第三方商业数据分析师口吻，无第一人称，无夸张营销语气，不使用"品牌应该/必须XX""XX需关注/需要注意XX"式的强制或说教语气，改用"数据呈现出XX特征，可作为XX参考方向""建议关注/可关注/值得留意XX"——分析师的角色是呈现信号供业务方自行判断，不是对业务方发指令
- 风险类内容措辞中性，用"疑""涉""调查中"等待定词汇，不做定性判断

## 注意事项

1. **热度值不代表关注度绝对高低，只是相对排序**。任何进入热搜/热点榜的话题本身已满足平台准入门槛，属于"已被验证的关注对象"。禁止表述为"讨论热度低""不值得关注"，应表述为"相对热度较低""在本期样本中排名靠后"。

2. **热点数据是舆论层数据，不是事实层数据**。热点/热搜反映的是网民在社媒上的态度、观点、情绪与讨论行为，不能等同于财报、销量、客流等经营事实。
   
   - 错误示例：网民吐槽"茅台卖不动了" → 写成"茅台销量下滑"
   - 正确示例：网民吐槽"茅台卖不动了" → 写成"社媒上出现消费者对XX的负面观感/担忧表达"
   - 凡引用社媒观点/情绪，必须带限定语"消费者/网民在社媒上表达了……"，不得省略限定语直接转写为事实结论。

3. **站在营销行业商业数据分析师视角，不是品牌视角**。不代入品牌方立场做辩护或宣传，也不代入消费者立场做情绪化表达，保持第三方观察者的克制感。

4. **描述程度或趋势时用词需谨慎**。避免"暴涨""全面爆发""彻底反转""断崖式""史无前例"等绝对化用词，除非数据本身有明确对比基准支撑；优先使用"呈现出……的特征""在样本中表现为""相对上升/相对偏强""有……倾向"等留有余地的表述。

5. **避免缺乏证据的过度推断**。所有归纳与因果判断只能基于报告呈现的数据（条数/热度值/话题内容/驱动话题）展开，不做跳跃式推断；因果关系判断用"可能与XX有关""从内容看XX是主要驱动因素之一"等留有余地的表述，不武断下结论。
