## 目标

按4个平台（微博/抖音/B站/知乎）各输出：热门事件TOPN + 平台热点词TOP3（候选<2个允许缺失）。

## 输入

下方「输入数据」段落，每个平台包含：热门事件TOPN表格（排名/事件名称/行业/热点总计/热度值/具体热搜），平台热点词TOP3表格（平台热点词/热度值/具体热搜，仅3列真实数据，候选<2个时该平台无此表格）。

## 步骤

对每个平台重复：
1. 转写热门事件TOPN表格（原样保留列、数字、具体热搜的链接，不改写不编造）
2. 按「热门事件洞察规则」判断写几句、写哪几条（不是固定1-2句，候选数决定）
3. 若平台热点词TOP3表格存在：结合「平台内容偏好参考」判断每条的"适配领域""借势方向"，转写为5列表格，不写整体观察句
4. 若平台热点词TOP3表格不存在：省略该平台此部分，不写"暂无"

## 热门事件洞察规则

目的：说明公众讨论/关注度落在哪里，挑出营销行业该注意的点——不是描述表格数据（热搜条数/热度值/行业分布不需要用文字复述一遍，表格里已经有）。

**候选数=1（TOP1）**：必须围绕这唯一一件事写1句。先说明"该平台本期热门话题集中在[事件]"（话题高度集中本身就是信号），再判断这件事有没有下表里的信号，有则补充说明，没有则只保留"集中在XX"这一层，不用编造额外信号。

**候选数≥2**：逐条按下表判断，只写有信号的事件，没信号的跳过（可能写1条，也可能写3条，不设固定数量）；全部候选都无信号时，不写"暂无信号"这类空洞表述，退回到整体基调判断——说明本期TOPN集中在哪类内容（如娱乐/竞技/情感），这类内容基调对营销窗口判断的参考价值是什么（如"话题集中在娱乐向内容，适合轻量借势，不适合严肃议题介入"/"本期话题热度集中在非商业领域，品牌借势空间有限"）。

有信号的候选数量超过200字能写的范围时，优先写标准化热度分（表格里的"热度值"列）更高的事件，热度分较低的让位。

这部分洞察整体不超过200字（不管写几条），信息密度优先于条数，条数多时每条压得更短。

| 信号类型 | 判据 | 怎么写 |
|---|---|---|
| 品牌/商业动作型 | 已有品牌方参与该话题（主动营销或被动卷入舆情） | 公众关注点落在哪个细节 + 品牌做了什么/舆情性质 |
| 风险/舆情型 | 负面事件、争议、消费者不满、企业危机 | 风险性质 + 相关品类需注意什么 |
| 消费态度/情绪信号型 | 反映某类消费行为、情绪倾向、值得留意的公众态度 | 这个态度/情绪信号，对哪些品类有参考价值 |
| 纯娱乐/八卦/竞技结果型 | 无以上任何信号 | 跳过（候选数=1时不适用，按上方"候选数=1"规则处理） |

## 平台内容偏好参考

| 平台 | 内容偏好 |
|---|---|
| 微博 | 话题讨论、梗图、表情包、文字互动玩法 |
| 抖音 | 手势舞、挑战、视频模板、变装 |
| B站 | 热门IP内容、深度解说、鬼畜/混剪 |
| 知乎 | 专业问答、深度讨论、经验分享 |

上表为示例形态，按当周该平台实际热搜分布判断，不局限于表中列出的形态。

## 平台热点词表格列定义

| 列名 | 来源 |
|---|---|
| 平台热点词 | 原样保留 |
| 热度值 | 原样保留 |
| 具体热搜 | 原样保留（含链接，不改写不编造） |
| 适配领域 | 判断产出：适合借势的品类/行业方向，不写具体品牌名 |
| 借势方向 | 判断产出，两步走：①先判断该词与消费/品牌场景的关联性强弱；②关联性强→写如何创作内容/如何改造热点获得传播；关联性弱/牵强→如实写局限（如"该词与消费场景关联较弱，不建议强行关联借势"），不为凑格式编造牵强的借势理由；若该词是风险话题（负面舆情/争议事件相关），直接写"风险话题，不建议借势" |

## 输出格式

按微博→抖音→B站→知乎顺序输出，每个平台：

```
### {平台名}

**热门事件 TOP {N}**

{按热门事件洞察规则写的洞察，0句到N句，视信号而定，候选数=1时至少1句}

{热门事件表格}

**平台热点词 TOP {N}**

{平台热点词表格，5列}
```

平台热点词部分只出表格，不加整体观察句。整体不超过1500字。

## 禁止

- 禁止：热门事件洞察部分超过200字（不管写几条）
- 禁止：写"暂无信号""暂无需要关注的点"这类空洞表述（无强信号时按"候选数≥2"规则退回整体基调判断，仍要有实质内容）
- 禁止：写"微博比抖音多"等跨平台比较句
- 禁止：某平台平台热点词候选<2个时仍输出该子版块或写"暂无"
- 禁止：在平台热点词表格后追加整体观察句（该部分只保留表格）
- 禁止：复述表格已有数据（热搜条数/热度值/行业名称）当作洞察，洞察必须落在"关注点+营销信号"
- 禁止：对无品牌/风险/情绪信号的纯娱乐事件也硬写一句（候选数≥2时应跳过，候选数=1时按"集中在XX"规则处理）
- 禁止：候选数=1时完全不写（哪怕信号弱，也要写"该平台本期集中在XX"这一层）
- 禁止：借势方向写具体品牌名
- 禁止：只输出3列平台热点词表格（必须补齐适配领域/借势方向2列）
- 禁止：对关联性弱的词编造牵强的借势理由（应如实说明局限，不硬蹭）
- 禁止：对风险话题给出正面借势建议（按列定义写"风险话题，不建议借势"）
- 禁止：写"XX团队应重点盯"等建议性指导语
- 禁止：写"XX平台一直偏娱乐"等超出单周数据的判断
- 禁止：改写「具体热搜」列的链接文本或编造未出现在输入数据里的链接
- 禁止：正文开头输出大标题
- 禁止：把输出包进 ` ```markdown ` 代码块
