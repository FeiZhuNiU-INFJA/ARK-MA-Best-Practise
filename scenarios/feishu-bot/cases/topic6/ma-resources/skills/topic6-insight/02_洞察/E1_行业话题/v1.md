## 目标

基于上周营销可用热点的行业分布数据，输出固定三句话洞察 + TOP10 行业表格。

## 输入

下方「输入数据」段落，包含：数据基础（总条数/行业总数）、辅助统计（TOP1/TOP3/TOP10占比、TOP1对TOP10倍数）、声量-热度错位候选（点名哪个行业写第二句）、TOP10行业表格（含次数标注的主要驱动话题）、环比数据（上期TOP10排序对比，或无上期数据的兜底说明）。

## 步骤

1. 从「数据基础」取总条数、行业总数 → 用于第一句
2. 从「辅助统计」取TOP3行业名+占比 → 用于第一句
3. 从「声量-热度错位候选」取行业名+声量排名+热度值 → 用于第二句
4. 从该行业「主要驱动话题」的1-3个事件名归纳出一个主题短语（去掉次数括号）→ 用于第二句"主要由……引发"
5. 从「环比数据」取变化描述或兜底措辞 → 用于第三句，原文照抄兜底措辞
6. 按「三句话模板」组装三句话
7. 按「表格列定义」转写TOP10行业表格

## 三句话模板

第1句：`上周营销可用热搜 {总条数} 条，共覆盖 {行业总数} 个行业，TOP3 行业（{TOP3行业名，用"+"连接}）热点数量合计占总数的 {TOP3占比}%，行业热搜数量{定性词}；`

- {定性词}：根据TOP3占比数值判断，占比高写"较多"/"较为集中"，占比低写"较为分散"

第2句：`「{声量-热度错位候选行业}」热点数量排名第{声量排名}，但行业热度值却达 {热度值} 分（TOP1），主要由{主题短语}引发，行业话题讨论{定性词}；`

- 若「声量-热度错位候选」标注"同时也是声量头部行业"（即该行业排名前3，无反差），改用平铺句式：`「{行业}」热点数量与热度值双双位居前列，主要由{主题短语}引发，行业话题讨论{定性词}；`

第3句：`与上期相比，本期{环比变化描述}。`

- 有上期数据：从TOP1变化/新进入/跌出/排名升降中挑1-2个转述
- 无上期数据：原文照抄「环比数据」给出的兜底措辞

完整示例（数字为示范，撰写时替换为「输入数据」的真实数字）：

```markdown
- 上周营销可用热搜 1724 条，共覆盖 26 个行业，TOP3 行业（影视综艺+游戏+科技/AI 产业）热点数量合计占总数的 40.6%，行业热搜数量较多；
- 「汽车出行」热点数量排名第九，但行业热度值却达 80.7 分（TOP1），主要由汽油价格与油车相关讨论引发，行业话题讨论较热；
- 与上期相比，本期为该系列首次归档，暂无上期数据可比。
```

## 表格列定义

| 列名      | 呈现要求                                              |
| ------- | ------------------------------------------------- |
| TOP10行业 | 原样保留                                              |
| 热点总计    | 裸数字，不加"条"字，不带 `<br>`                              |
| 热度值     | 裸数字（如 `78.4`），不加"分"字，不带 `<br>`                    |
| 主要驱动话题  | 去掉"(N次)"次数括号，改成 `- 事件名` 的无序列表，条目间用 `<br> <br>` 连接 |

事件簇名不足3个时有几个写几个，不用"—"补齐；完全没有数据时该格填 `—`。

表格示例：

```markdown
| TOP10行业 | 热点总计 | 热度值 | 主要驱动话题 |
| --- | --- | --- | --- |
| 影视综艺 | 293 | 78.4 | - 蜘蛛侠4宣发<br> <br>- 电影欢迎来龙餐馆点映口碑票房<br> <br>- 剧集《九门》角色互动花絮热传 |
| 科技/AI产业 | 152 | 80.1 | - DeepSeek斩杀线<br> <br>- DeepSeek API涨价公告与原因讨论<br> <br>- 中际旭创回应美国光模块禁令影响 |
| 游戏 | 129 | 76.8 | - 和平精英刺激之夜晚会明星COS直播<br> <br>- 恋与深空敖尹下线玩家争议回归<br> <br>- 火影手游9月版本前瞻 |
```

## 输出格式

**行业洞察：**

第一行：三句话（`- ` 开头无序列表，第1、2句句末"；"，第3句句末"。"）
第二部分：TOP10行业表格
不加标题，不加结尾段落，三句话整体不超过200字。

## 禁止

- 禁止：编造数据基础/辅助统计里没有的数字
- 禁止：把"表格只展示TOP10"理解成"上周热点只涉及10个行业"
- 禁止：自行心算TOP3/TOP10占比或倍数，与「辅助统计」不一致
- 禁止：第二句自行挑选行业（必须用「声量-热度错位候选」给出的行业）
- 禁止：第二句照抄原始事件名全文（必须归纳成主题短语）
- 禁止：没有上期数据时编造环比变化
- 禁止：表格热度值带"分"字或写最高值（口径是中位数）
- 禁止：表格主要驱动话题保留次数括号
- 禁止：表格"热点总计""热度值"列出现 `<br>`
- 禁止：正文开头输出大标题
- 禁止：把输出包进 ` ```markdown ` 代码块
- 禁止：写"密集月份""全年趋势"等单周数据不支撑的推断
