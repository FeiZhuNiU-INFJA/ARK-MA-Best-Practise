## 任务1：舆情风险打标

### 风险类型分组参考

| 风险类型 | 触发关键词 |
|---|---|
| 政策性风险 | 制裁、禁令、出口限制、合规、被罚 |
| 食品/产品安全 | 异物、超标、中毒、配方、召回、不合格 |
| 高管言论 | 高管、CEO、创始人、言论、回应、道歉 |
| 品牌危机公关 | 翻车、公关、声明、致歉、反转 |
| 明星主体风险 | 塌房、偷税、违规、虚假宣传 |
| 文娱作品口碑 | 口碑崩塌、烂片、撤档、差评 |

给每个候选选1个最贴切的类型；实在不属于任何已列类型可以新起一个类型名（比如"技术/产品安全"），不要为了塞进已有类型而勉强——但新起类型前先看清楚候选内容跟哪个已有类型的语义更接近，比如"批量劝退应届生""贴牌酒店遇冷"这类，本质是"品牌经营/服务口碑出问题"，应该归"品牌危机公关"，不要因为触发词表面像"高管言论"（有CEO/回应字样）或者随便找一个不相关的类型（比如"文娱作品口碑"）就归错类——判断依据是事件的**实质内容**，不是表面关键词命中。

### 乙方可接性判断标准

站在**乙方品牌公关公司**的视角判断：这个舆情事件，普通品牌公关能不能接手做应对？

**接**：品牌信任问题、事实相对清楚、客户能配合整改、不碰法律/财务/政治/安全红线。典型如：营销文案翻车、产品质量投诉、代言人言论争议、服务体验类吐槽——这类事件的应对空间是"舆情研判、声明口径、内容下架、评论区管理、后续品牌修复"，普通品牌公关的专业能力用得上。

**不接**：核心是财务、证券、法律诉讼结果、政治敏感、人身安全等**硬事实不可逆**的问题，普通品牌公关改变不了这类事实本身。典型如：企业财报亏损/退市、刑事案件判决结果、政策性合规通报、重大安全事故死亡人数——这类不代表事件不重要，只是超出"品牌公关能怎么应对"这个框架，该转给财经公关/律所/政府关系等专业方处理，普通品牌公关最多做辅助（合规媒体沟通、舆情监测），不该跟"接"的案例混在同一个洞察框架里。

判断时看**事件的核心矛盾是什么**，不是看事件大不大：比如"某明星被曝税务问题"如果核心是"税务违法事实"，接近不接；但如果候选描述的核心是"品牌因代言人负面需要评估解约/发声"，这是品牌公关能接的应对面，算接。拿不准时倾向"接"（宁可让人工在最终报告里多看到一条边界案例，也不要漏判导致有价值的候选被误伤排除）。

## 任务2：合作动态打标

### 变动类型分组参考

| 变动类型 | 触发关键词 |
|---|---|
| 新代言官宣 | 代言、官宣、签约、代言人 |
| 品牌联名/跨界 | 联名、X×Y、跨界、联动 |
| 品牌合作资源变动 | 战略合作、上线、推出、发布 |
| 明星/IP合作 | 演唱会嘉宾、同框、影视选角、合拍 |
| 合作破裂/负面 | 终止、解约、违约、纠纷、坠亡、失信 |

### 对营销人是否有参考价值判断标准

**有用**：涉及艺人/IP商业价值变化、品牌跨界联名新玩法、合作破裂舆论风向转变——能给营销人提供"谁在跟谁合作/怎么合作/合作出了什么问题"这类可参考的信号。

**无用**：纯技术/供应链/内部业务新闻（比如系统适配、专利费支付、供应链验证、内部管理政策调整），不涉及创意/传播/代言/受众触达，对营销从业者没有决策参考价值——这类候选哪怕热度分很高也判无用，热度分不是参考价值的替代指标。

**"品牌合作资源变动"这个类型要特别收紧**：只有"带来新的传播资源/渠道触达能力变化"的合作才判有用（比如平台开放生态资源、可能带来达人/流量扶持的合作），纯技术采购/供应链验证/内部系统适配（比如"XX适配鸿蒙""XX向XX支付专利费""XX联合XX验证零部件可靠性"这类）判无用——这个类型历史上混入过大量这种候选，是本次打标要重点把关的地方。
