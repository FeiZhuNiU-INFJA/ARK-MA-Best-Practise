## 口径红线快照

| 口径 | 取值 | 说明 |
|---|---|---|
| NSR 分母 | **含中性**(`nsr_denominator_includes_neutral=true`) | 三处权威文件一致;实现读 `state.params` 不硬编码 |
| 指标白名单 | 条均互动量 / 品牌提及率 / 产品提及占比 / NSR | 活动层指标名仅限此四 |
| 禁用措辞 | 人均 / 转化率 / 转化 / 性价比 | 命中即 P0 |
| 提及漏斗 | 产品提及 ⊂ 品牌提及,占比 ≤ 1 | 嵌套关系 |
| 多活动 | 逐个算、不相加 | 禁「总声量 / 合计声量」 |
| 日期 | 发表时间 `publish_time`(epoch ms, CST) | — |
| 去重键 | `fingerprint → id → item_id → url` | 优先级链 |
| 情感 | AI 标注为准,活动相关行缺 AI 情感**报错不兜底** | SSJH 情感 int(1/0/-1) |
| 竞品分析 | 已下线(SOV / 3.2 章) | — |
| 标注分流阈值 | ≥1000 行走 DataHub 批量引擎,否则小引擎/降级 | `annotation_routing_threshold` |
| QC 上限 | `qc_max_rounds=3`,`pass_policy=p0_count==0` | 超限走 HC7 |

## 运行标准

- `demo` 只用于 Gateway 的 G1 表单默认值；流水线内与 `full` 标准完全一致。
- 适配层可以产生 `degraded: true` 诊断产物，但生产 handler 必须 fail-closed，禁止其进入报告或交付链。
- 图表为本地 PNG，由 n20 上传飞书 media；没有外部对象存储依赖。
