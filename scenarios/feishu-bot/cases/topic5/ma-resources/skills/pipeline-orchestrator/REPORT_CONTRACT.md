# 报告内容与交付契约

本契约依据客户 KS_Report_Template、KS_Feishu_Format 和 Producer 提示词整理。
与旧材料冲突时，以当前业务口径为准：NSR 默认含中性，使用条均互动量，
竞品章节已下线，图片使用飞书原生 media。五章结构保持不变。

词云链路为 n14 双版渲染 → n15 全词表议题分析/可选原帖阅读/compose → n16 报告装配。采用客户 `wordcloud-insight` v0.2.6；完整词表保留原值与原词，不删除否定词、品牌词或合并同义词，仅绘图稳定排序展示前100词。不得用展示集合限制分析。

报告默认引用 `wordcloud.png`（默认1400×880、RGBA透明），同时保留同布局RGB白底 `wordcloud-white.png`，明确要求统一白底时可使用白底版。双图须通过哈希、白底逐像素合成、展示集合完整性和零重叠检查。默认按客户优先顺序自动选字体：Windows优先微软雅黑粗体，其他系统优先Noto Sans CJK粗体；词云Skill随包提供Noto Sans CJK Bold，不再默认强制思源黑体。显式配置客户字体时才传--font；实际字体和哈希记入render.json。

议题最多5个，少证据可仅1个，不强制建议。已有原帖采用 schema2 全文字段定位和按判断选择的关键原句，抽样与补读由语义模型完成。交付前再次复核标题与正文判断强度、原句支持、否定条件及OCR角色，不能把商品页宣称当成用户体验。无可用正文正常按词表分析；有正文但读取/定位/证据失败不得静默跳过。ERROR、NEEDS_SETUP、PARTIAL 不得向 n16 声称完成。analysis.md、preview.html、analysis-evidence.json 留在各范围新输出目录，内部 rationale 不进入业务正文。

PGC 热门表字段：排名、标题、内容≤100字、内容类型、站点名称、作者、URL、总互动量。
UGC 热门表字段：排名、内容≤100字、站点名称、URL、总互动量。
UGC 不展示个人作者；PGC公开机构/KOL作者仅在热门表展示。无标题UGC不得丢弃正文。
Markdown表格中的合法竖线须转义，禁止删列、截短榜单或编造作者。

观点占比以对应正面或负面全部内容为分母，每观点展示2–3条实际代表原文，
可用原文不足时如实显示。某情感方向少于10条时披露小样本；分维NSR样本少于30条
不输出确定性NSR。UGC类别占比以活动相关UGC为分母，每类展示1–2条代表内容。
观点和UGC原文均必须来自统计证据，不能以类别的通用定义替代样本分析。

词云按品牌大盘、活动及其整体/品牌/产品维度分别处理，平台独立不合并。
每组默认2–4个议题、最多5个，低证据可仅1个；给出原词、词频和含义，不强制行动建议。
引用只用于内部证据绑定，不在词云议题处展示帖子原文。有原帖证据失败时停止；
无原帖时按词频分析，不生成无依据解读。
模型选择候选 `quote_id`，代码复制标题/正文/OCR 中的原字段片段，拒绝未知、
跨字段或冲突引用。候选与最终原词集合均须精确属于当前范围且无重复；
证据帖子须在已读白名单内，未读先补读。具体失败反馈包含议题、未知词、
重复词或未读帖子以及允许集合，进入局部重试，不静默删词或伪造原句。

分析节顺序：洞察和正文分析 → 图表 → 必要数据表 → 代表内容。
词云左图右解读；情感和漏斗左图右表；正负观点双栏；多平台传播结构双图并排。
漏斗图与数据表使用55:45双栏。表格填值复用单元格已有段落，禁止额外插入空段落；
清理历史多余段落时仅删除已确认的空文本段落，遇到非空内容停止自动处理。
正文按标准800px内容宽度计算表格总宽；双栏扣除24px间距后按栏比例分配，
Callout内扣除32px内边距。长正文/代表原文/关键词列分配更多空间，排名与数字列较窄。
每列至少50px；列数过多无法放入容器时保留最低可读宽度，由飞书横向滚动展示。
发布回读必须确认实际列宽与计算值一致，且每个单元格仅含一个文本段落。
飞书 HTTP 429 在单请求层指数退避，并尊重 Retry-After；最多六次请求、60秒恢复窗口。
HTTP 503 仅重试读取、绝对值替换或携带 client_token 的幂等请求；创建块和无幂等键的
插入操作不能盲目重放。权限失败或恢复窗口耗尽仍报错，由发布节点处理。
数据说明用普通正文和表格。单平台省略平台分布饼图，用文字说明。
不泄漏本契约、内部路径、字段名或布局操作指令。

写作模型负责有证据的叙事；报告装配器负责固定字段、榜单、代表原文和图片位置。
报告不达结构或口径要求时停止，禁止整篇静默替换成简化模板。

返修保留所有编号章节。热门内容区按章节层级整体替换，包括已有子标题与旧表格，
由代码从统计产物重建品牌和每活动的 PGC/UGC Top10；不得依赖模型保留表格数据。
完整性检查按编号识别章节，兼容 Markdown 标题与编号加粗标题；热门表检查实际字段、
行数和源数据，无可用内容时必须如实披露，不能只凭标题判断完成。
每次修订的结构或证据校验失败，都回传具体问题并使用上一版有效完整正文继续返修。
节点内最多三次尝试，仍未通过则停止；确定性预检通过后仍须独立 Validator 复检。

数据说明替换不得越过整体洞察标题，兼容 Markdown 各级标题和独立加粗标题。
篇头将数据说明与整体洞察合并时，保留原叙事正文，并在前面补充确定性数据说明。
报告装配后再次校验必需章节和禁用口径，校验通过后才保存；返修耗尽须返回具体问题。
词云节点对议题名称、含义和行动建议执行相同禁用口径校验；命中后按原词与帖子证据
重新生成，最多三次。不得把含无依据效果建议的词云解读交给报告装配器。
